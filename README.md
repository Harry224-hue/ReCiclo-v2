# ReCiclo v2.0 ♻️

[![Compilar y Validar ReCiclo Web](https://github.com/Harry224-hue/ReCiclo-v2/actions/workflows/build.yml/badge.svg)](https://github.com/Harry224-hue/ReCiclo-v2/actions/workflows/build.yml)

> **ReCiclo — Visión Inteligente para Reciclaje en el IT Morelia**  
> Aplicación web progresiva multiplataforma con IA para reconocimiento y clasificación automatizada de residuos sólidos.

---

## 🚀 Novedades de la Versión 2.0

- **Mejoras en el Mapa:** Mapa interactivo con localización de botes en Campus 1 y 2, filtros por tipo de residuo y rutas a pie.
- **Mejoras en el Escáner:** Identificación rápida y precisa con inteligencia artificial por cámara y subida directa de fotografías.
- **Mejoras en el Perfil:** Historial sincronizado en la nube, contador de racha ecológica y medallas de logro para la comunidad del IT Morelia.
- **Personalización y Museo:** Selector de temas y paleta de colores, y el archivo histórico con las versiones de desarrollo.

---

## 🛠️ Tecnologías Principales

- **Frontend:** React 19 + TypeScript + Vite
- **Estilos:** Tailwind CSS v4 + Framer Motion + Lenis Smooth Scroll
- **Visión por Computadora / IA:** TensorFlow.js MobileNet + Google Gemini Vision API
- **Backend / Datos:** Firebase Authentication & Cloud Firestore
- **Mapas:** Leaflet / OpenStreetMap

---

## 💻 Desarrollo Local

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor de desarrollo
npm run dev

# 3. Compilar para producción
npm run build

# 4. Validar linter
npm run lint
```
