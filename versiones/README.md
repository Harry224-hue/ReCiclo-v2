## Cómo ejecutar una versión localmente

Cada carpeta de versión cuenta con su propio archivo `package.json` y configuración de Vite. Para ejecutar cualquiera de las versiones de forma independiente:

```bash
cd versiones/v1.9
npm run dev
```

Las versiones también pueden ser exploradas directamente desde el navegador en la ruta `/museo` de la aplicación principal.
